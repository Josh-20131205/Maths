# 🎈 数学计算 (Math App)

一个专为儿童设计的全屏、防沉迷、带连击音效的数学计算小软件。

## ✨ 核心特点

*   🖥️ **全屏防沉迷**：全屏运行，屏蔽系统快捷键，防止孩子切屏玩游戏。
*   🔊 **连击音效反馈**：做对题目有清脆音效，连对还会触发“Combo”特效，激发孩子学习兴趣。
*   📝 **智能错题本**：自动记录做错的题目，支持随时订正。
*   🔐 **家长专属设置**：
    *   支持自定义数字范围（加减乘除）。
    *   支持限制计算结果范围。
    *   支持设置家长密码，防止孩子修改设置。
*   💾 **数据本地保存**：做题记录和错题本保存在本地，安全可靠。
